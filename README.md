# Data Portal UI — Selected Modules

Selected **Vue** components from a data / AI portal: data cards, modal, time-info cards, pagination, and helpers.

> UI samples from a larger portal app.

## What’s included

### Components

| File | Role |
|------|------|
| `DataComponent.vue` | Data distribution card with icon + list |
| `DataModalComponent.vue` | Modal wrapper for data details |
| `DataTimeInfoCard.vue` | Time / status info card |
| `Pagination.vue` | List pagination control |
| `Icon.vue` | Icon helper component |

### Utils

| File | Role |
|------|------|
| `utils/helpers.ts` | Shared helper functions |

## Tech stack

Vue 3 (`script setup`), TypeScript
